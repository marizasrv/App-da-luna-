Inclui:
- alfabetização
- matemática
- conhecimentos gerais
- 5 desenhos para colorir
- 4 histórias para dormir
- botão Ouvir história e Parar (narração em português pelo navegador)

Para atualizar no GitHub:
1. Substitua o app.py antigo pelo novo.
2. Mantenha requirements.txt.
3. Mantenha/envie a pasta assets.
4. Faça Commit changes.
5. O Streamlit deve atualizar o app automaticamente.
